Este repositório contém a implementação de um diagrama de classes para cálculo de áreas (Quadrado e Retângulo) e classificação de triângulos (Equilátero, Isósceles e Escaleno), acompanhado por testes unitários desenvolvidos com JUnit no NetBeans para validar o funcionamento de todos os métodos.
